How it works

Three components. One overnight loop.

01 · YOU WRITE

Feature plan

Todo file with checkboxes. Each task has an Implementation paragraph and a testable Validation criterion. The runner parses it strictly.

02 · HARNESS RUNS

Runner script

Bash harness extracts next task, calls claude -p, runs the validation gate, retries on failure up to MAX_FIX_ATTEMPTS, marks done.

03 · AGENT BUILDS

Codebase context

Heredoc with your file map, conventions, forbidden patterns. The agent has no memory between calls — this is its only map.

Phase 1: Implement Claude writes code + tests Phase 2: Validate prettier · tsc · eslint · test runner → Fix loop up to MAX_FIX_ATTEMPTS (default 7) Phase 3: Chrome optional live browser test via Claude-in-Chrome MCP → Fix loop up to MAX_CHROME_FIX_ATTEMPTS (default 3) Phase 4: Mark done checkbox [x] in todo file

Failed tasks get [x] — NEEDS MANUAL REVIEW and the loop moves on. You triage in the morning.

Cost and safety

Nightshift spends real money and modifies code unsupervised. Read this before launching.

WARNING

Default overnight run costs $8–50 (Sonnet) or $25–100 (Opus). A 100-step Bulletproof sweep can hit $500.

Always set MAX_ITERATIONS — the iteration cap is your worst-case cost cap. Set Anthropic Console spending limits as a hard ceiling.

The agent edits files autonomously. Commit work you care about before launch. Protect main via branch protection.

What it’s for

Multi-task batches where validation can be programmatic. Not for single bugfixes or judgment-heavy decisions.

PRIMARY

Overnight feature batches

5–20 well-spec’d tasks with tests as oracle. Agent implements while you sleep. You review the diff at breakfast.

BULLETPROOF MODE

Production hardening sweeps

Quarterly security/accessibility/perf passes. Branch + commit per step + PR + review-comment self-healing. Wake to a clean PR.

USE CASE

Mechanical migrations

Tailwind v3→v4, React 18→19, dep bumps. File-by-file, validation gate catches regressions.

USE CASE

Test backfilling

Add tests to legacy code one file at a time. Validation = test runs + coverage threshold rise.

vs alternatives

Niche: you trust the model to write code, want a strict validation gate, and want it detached so you can sleep.
